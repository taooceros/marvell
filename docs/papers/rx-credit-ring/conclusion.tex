\section{Conclusion}\label{sec:conclusion}

Preventing Leaky DMA without dropping network bursts does not require splitting the receive path into separate fast and slow rings, rewriting per-flow steering tables, pausing fast-path delivery during drain, or maintaining a two-producer software merge ring. By treating the NIC as an active credit-paced producer that buffers bursts in its own memory hierarchy by default and pushes strictly in order into a single L3-pinned 256~KiB host hot ring (extended to compact $\le$2~MiB DMA receive rings for large Ethernet frames), \sys{} achieves proactive LLC isolation with an $O(1)$ per-ring credit check.

Across 1,089 verified zero-error hardware runs on an unmodified PCIe Gen5 server and Marvell OCTEON~10 CN106 100GbE SmartNIC, \sys{} adds just 6~ns at zero backlog, maintains a flat 0.905~$\mu$s steady credit-refill hop across 128~MiB bursts, eliminates 98.9\% of host DRAM traffic at 100.0\% DDIO, and protects co-located 32~MiB KV $p99$ latency at 41--42~ns with zero packet loss. Integrated into our end-to-end DirectPush datapath over 100GbE, it saturates 100GbE RX on a single host core and accelerates a dual-host 32.5~MiB KV server by up to 55\% in throughput while cutting open-loop $p99$ latency by 50--64\% over a tuned asynchronous descriptor-ring baseline.
