\section{Implementation}
\label{sec:implementation}

We prototype \sys{} and all baselines in Rust and C atop DPDK~26.10.1
(\texttt{octeon\_ep} host VF PMD and \texttt{cnxk} SmartNIC PMD), leaving the
SDP DMA hardware, descriptor format, Linux kernel, and firmware unchanged.

\paragraph{Testbed.}
A passive 100GbE copper link (Ethernet PAUSE disabled and verified zero)
connects three hosts:
\begin{itemize}
\item \textbf{Host (\texttt{saturn}):} Dual-socket Intel Xeon Gold~6438M
  (Sapphire Rapids), evaluated on NUMA Socket~1 (32 physical cores, 60\,MiB
  L3, $\sim$8\,MiB 2-way DDIO; cores pinned at 3.90\,GHz single-core and
  3.60--3.90\,GHz across 8 cores; uncore/mesh pinned at 2.20\,GHz). Socket~1
  has 2 active DDR5 channels ($2\times 32$\,GiB, $\sim$50--60\,GB/s);
  \S\ref{sec:eval} explicitly separates channel-independent LLC-miss invariants
  from 2-channel DRAM queuing amplification.
\item \textbf{SmartNIC (Marvell OCTEON~10 CN106):} \texttt{crb106-pcie} on
  Socket~1 PCIe Gen5~$\times 4$ (126.03\,Gbps physical payload ceiling after
  128b/130b), with 24 Neoverse-N2 cores (2.00\,GHz), 48\,MiB shared L3 (TAD),
  48\,GB 6-channel DDR5, and a 100GbE \texttt{NIX0} MAC inline with the
  \texttt{SDP} DMA engine.
\item \textbf{Generator (\texttt{mercury}):} ConnectX-5 100GbE running
  user-space multi-threaded drivers for 64\,B (RoCEv2 UC), 254--1400\,B
  (RoCEv2 UD), and 1500\,B (UDP GSO) frames across Poisson, microburst, incast,
  and flow-churn profiles.
\end{itemize}

\paragraph{Host DPDK additions, BAR4 lease, and ISM trade-off.}
The host uses standard AVX2 \texttt{octeon\_ep} SDP DMA rings and
\texttt{rte\_eth\_rx\_burst()}/\texttt{rte\_mbuf} with two \sys{} additions:
(1)~a $\sim$6-line unfenced \texttt{MOVDIR64B} credit hook in our Rust RX loop
after packet release (Algorithm~\ref{alg:creditring}), movable into
\texttt{rte\_eth\_add\_rx\_callback()} or PMD refill after \texttt{SLIST\_DBELL};
and (2)~a 16-LoC (+12 net, 3 files) \texttt{allow\_small\_oq=1} devarg relaxing
the 2,048-slot ring floor to 256 ($W_{\text{mark}}=\min(256,D/4)$). Two
orthogonal PMD patches apply uniformly to all baselines: optional
\texttt{rx\_poll\_mem=1} polling (+139/-5 LoC, 4 files; E3/E5 only, not needed
by \sys{}) and a 9-LoC (+5 net) Socket-1 NUMA fix in \texttt{otx\_ep\_ism\_setup()}
(165 ins / 13 del total). In 8-core E4, \texttt{ism\_enable=1} emitted
$\sim$50\,Mops/s of empty-poll MMIO writes (capping 254\,B at 31.7\,Gbps);
\texttt{ism\_enable=0} cut MMIO 75$\times$ and hit 99--100\,Gbps (sync reads
cap 8-core 254\,B at $\sim$45\,Mpps, RTT 7.6--8.4\,$\mu$s). We use
\texttt{ism\_enable=1} in E1--E3/E5 and \texttt{ism\_enable=0} in E4/E6;
credits write BAR4 Window~15 under a TCP nonce lease restored on exit.

\paragraph{Unmodified applications and faithful baselines.}
We link upstream \textbf{Memcached~1.6.45} (\texttt{git diff = 0} lines
modified) via a thin C adapter handing DPDK \texttt{mbuf}s directly to
Memcached's binary protocol parser and slab allocator, alongside a 5-tuple
stateful NFV pipeline (NAT and Maglev LB~\cite{eisenbud2016maglev}). All
baselines run on identical CN106 + standard SDP rings: \texttt{privRing} /
\texttt{Large SDP} (2048--8192 descriptors, 32--180\,MiB FIFO or LIFO pools,
using a software host backlog in E2 so 128\,MiB bursts exceed CN106's 8192/Q
hardware cap without dropping); static \texttt{ShRing*} (1024-slot shared ring,
TTAS spinlock, no fallback to \texttt{privRing}); \texttt{rxBisect} (lock-free
\texttt{lf\_stack} $A_x$ + per-core $B_x = 8192$ host rings); and strengthened
\texttt{CEIO} (equal 1,024-packet host budget, dedicated 5th SmartNIC control
core, 20\,$\mu$s + per-pull credit flushes, strict FIFO phase-hold guaranteeing
0 out-of-order packets, 2048-slot fast pools, slow-path DMA rings, and 2P1C
\texttt{SwMergeRing}; in E5, \texttt{CEIO-style} parameterizes 25\,$\mu$s
switch lag and 15\,$\mu$s phase pauses while sharing \sys{}'s 5,119-\texttt{mbuf}
pool and $O(1)$ flow array).
